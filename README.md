# Windows r2 distribution

Based on v1.05.9 KO. Extract the entire ZIP and run the EXE with the PCK beside it.
Removes F4/F5 automation, automatic choices, video recording/letters/library, and the F3 web trainer including its HTTP server and web UI. F2 remains available.
Includes the supplied save, payload, overlay and tables folders. Only obsolete feature settings/video records were removed from supplied saves.
The ZIP is stored with Git LFS. See SHA256SUMS and verification.json.
Static/script/archive checks passed; Windows gameplay has not been tested. No Android app is included.
